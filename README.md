# homebrew-tap

Homebrew tap of AlfrescoLabs. These tools are not official Hyland products, and Hyland does not officially support them.

| Cask | What it is |
| --- | --- |
| `openarch` | [CLI for OpenArch](https://github.com/AlfrescoLabs/openarch-cli) |
| `openarch-app` | [openarch-app](https://github.com/AlfrescoLabs/openarch-app), the plugin of the CLI for OpenArch that runs App for OpenArch. It also installs `openarch` |

```sh
brew install AlfrescoLabs/tap/openarch
brew install AlfrescoLabs/tap/openarch-app
```
